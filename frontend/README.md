# Frontend

React 19 + Vite + Leaflet. See the root README for the full project overview.

```bash
npm install
npm run dev      # http://localhost:5173 (proxies /api to http://localhost:8000)
npm run build    # production bundle in dist/
npm run lint
```

Set `VITE_API_URL` (see `.env.example`) to the deployed API URL when building for production.
